# HorizonTechX Tasks

This repository contains projects completed as part of HorizonTechX tasks.

## Task 1: E-Commerce Web Application

### Description
A simple E-Commerce Web Application developed using Python Flask and SQLite. It allows users to browse products and manage their shopping cart.

### Features
- Product listing and search
- Category filtering and sorting
- Shopping cart and wishlist
- Product ratings and reviews
- Discount coupons
- Stock management
- Order history and cancellation

### Technologies Used
- Python
- Flask
- SQLite
- HTML and CSS

### How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Install Flask:

   ```bash
   pip install flask
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.

### Note
This is a student demonstration project. Checkout is simulated, and real online payments are not supported.
